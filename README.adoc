[#_organization_of_the_samples]  
== 📂 示例组织结构  

每个示例均位于独立的子文件夹中，无需依赖其他示例即可运行。此外，我们提供了一个包含所有项目的 `*.sln` 解决方案文件，方便您一站式查看所有示例。  

示例列表请见 <<samples,下方>>。示例按类别和难度分类，并标注了**关键词**以方便搜索。  

每个示例文件夹中均包含一个 `README` 文件，详细说明示例内容，并提供相关文档链接。  

[#_difficulties]  
=== 🐣 难度等级  

每个示例均标注了难度等级，用于说明用户需要具备的基础知识水平。  

[cols="1,1,2"]  
|===  
| 🔘 | 难度 | 所需知识  

| 🐣 | 初学  
| 无需 Avalonia 基础，但需掌握 `C#`、`X(A)ML` 及 IDE 的基本使用。  

| 🐥 | 简单  
| 需了解 Avalonia 的基础知识。  

| 🐔 | 普通  
| 需具备一定的 Avalonia 使用经验。  

| 🐉 | 困难  
| 专注于非标准任务，适用于高级用户。  

|===

若发现示例内容不清晰或缺失，可修改后提交 PR。拼写错误或表述问题也可通过 PR 修正。  

重要：若修改难度或关键词，请同步更新主页面。  

[#_adding_a_new_sample]  
==== 添加新示例  

1. 将新项目添加到解决方案：`src ► Avalonia.Samples ► Avalonia.Samples.sln`  
2. 在示例根目录添加 `README` 文件。建议使用以下模板：  
   - link:/_docs/AsciiDoc-Template/[AsciiDoc 模板]：支持富文本内容。  
   - link:/_docs/Markdown-Template/[Markdown 模板]：若不使用 AsciiDoc，可选择此模板。
